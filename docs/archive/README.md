- 归档内容可能反映旧分支、旧任务、旧文件结构或当时的待确认事项。
- 当前任务以 `docs/ai/CURRENT_TASK.md` 为准。
- 强门禁以 `docs/ai/RULES.md` 为准。
- 当前操作流程以 `docs/ai/WORKFLOWS.md` 为准。
- 产品与技术 Final 决策以 `docs/ai/DECISIONS.md` 为准。
- 归档材料不得自动恢复为当前规则、当前计划或执行依据。
