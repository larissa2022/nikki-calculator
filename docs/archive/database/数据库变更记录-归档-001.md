### 基本信息

### 变更目的

- 允许普通登录用户修改自己的专属代号 `profiles.username`。
- 避免开放 `profiles` 整行 update 权限，防止用户绕过前端修改 `role_level`、积分、额度等敏感字段。
- 修复昵称保存后页面仍显示匿名代号或邮箱的问题。

### 影响范围

| 对象 | 影响 |
| --- | --- |
| 表 | `profiles` |
| 字段 | 仅通过 RPC 更新当前用户自己的 `username` 和 `updated_at` |
| RPC | 新增 / 替换 `update_profile_username(p_username text)` |
| RLS / Policy | 不新增普通用户整行 update policy |
| 前端模块 | `UserProfile.vue`、`MainView.vue`、`App.vue`、`AuthBar.vue` |
| 线上用户影响 | 未推生产前无影响；推生产后用户可设置并立即看到专属代号 |

### 变更内容

- RPC 校验用户必须已登录。
- RPC 校验用户名非空、长度不超过 24 个字符，且不能使用 `匿名搭配师_` 保留前缀。
- RPC 使用 `security definer` 只更新 `auth.uid()` 对应 profile。
- 前端保存昵称后立即使用 RPC 返回的 profile 做本地展示更新。
- 顶部用户展示优先显示 `profile.username`，未设置时继续显示邮箱。
