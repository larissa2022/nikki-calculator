# 奇迹暖暖极速搭配器操作手册

适用版本：社区共治 V2.1 开发预览版。更新日期：2026-10-11，北京时间。

这份手册按六大功能介绍：先用自己的衣柜算搭配，再了解图鉴补录、陪审投票、报错、积分和管理员操作，最后聊聊这个项目。视频也可以按这六章依次讲解。

以下规则沿用已冻结的 V2.1、原等级设计和站长权限。手册说明开发预览版的已实现功能，不表示已经在正式网站上线。

## 1. 核心搭配器：录入衣柜、计算搭配与完善图鉴

搭配器的核心用途，是从你已经拥有的服装里，找出适合竞技场主题的高分搭配。先把衣柜录准确，计算结果才真正适合你。

### 1.1 先登录，让衣柜跟着账号保存

点页面顶部“登录开启云端同步”，填写邮箱和密码，再点“立刻登录”。登录成功后，顶部会出现你的名称和“个人中心”。

没有账号，点“没有账号？点击注册”，按提示填写信息、获取邮箱验证码并完成激活。忘记密码，使用登录窗口的“忘记密码？”入口。不要向他人发送密码或验证码。

未登录也能体验搭配计算，但用的是全图鉴，不代表你拥有推荐部件。想保存并用自己的衣柜计算，请先登录。

### 1.2 把已拥有的服装录入衣柜

入口：首页“录入衣柜”。

按名称录入：

1. 选择“按名称录入”，填写游戏里的准确服装名称。
2. 多件服装用逗号或换行隔开，点“录入到云端衣柜”。
3. 在结果报告里核对成功录入、重复和未找到的项目。

按编号录入：

1. 选择“按分类短编号录入”，先选部位分类，再填数字短编号。
2. 多个编号用逗号、空格或换行隔开，点“录入到云端衣柜”。
3. 查看结果；同一编号匹配到多件服装时，改用准确名称录入。

已经拥有的服装不会重复加入。名称录入要填散件名称，不要把整套套装的名字当作一件服装。

录入后，到“我的衣柜”按名称或分类检查。误录的单件可点“×”移除；多件可用“批量操作”，选中后点“删除”。这里只移除自己的拥有标记，不会删除公共图鉴或游戏服装。

### 1.3 图鉴没有这件服装？顺着结果完善资料

操作路线：“录入衣柜 → 图鉴缺失项 → 完善资料”。

1. 在录入结果中找到未收录的服装，先确认名称、分类和短编号没有填错。
2. 在“图鉴缺失项”中点“完善资料”。
3. 对照游戏填写名称、分类、短编号、星级、五组属性和套装状态；特殊标签可以不填。
4. 点“提交图鉴申请”，看到提交成功后等待审核。

套装状态请分清：

- 知道属于哪套：选择已有套装；尚未收录时，可按表单的“一键申请并应用”提示申请。
- 确认是纯散件：选择“无关联套装（纯散件）”。
- 暂时不清楚：选择“所属套装待确认”，不要用“纯散件”代替。

提交申请不等于立即入库或加分。被驳回后，可在“个人中心”的“需要重新提交的服装资料”查看原因，再按原因修改并重新提交。遇到额度或网络提示时，先查看记录，不要连续重复提交。

### 1.4 用搭配器算出推荐组合

1. 点首页“搭配计算”。
2. 在“选择竞技场主题”里选本次主题。
3. 查看“预计极限总分”和各部位的推荐服装；需要时点部件旁的复制按钮复制名称。

登录后只使用你已录入的衣柜。衣柜为空，点“去录入衣柜”；读取失败，点“重新读取衣柜”。系统不会用全图鉴冒充你的衣柜。预计分数供搭配参考，以游戏实际结果为准。

### 1.5 已经集齐的套装，可以整套录入

入口：首页“套装图鉴”。

1. 搜索套装，点卡片查看部件；“全部 / 已集齐 / 未集齐”可以筛选。
2. 确认游戏中确实已拥有全部部件后，在上方填准确套装名，点“一键全部集齐”；单套也可点“一键补齐部件”。
3. 只想调整部分部件时，在套装详情修改拥有状态，再点“确认并保存修改”。

这些按钮只是记录“我已拥有”，不是领取游戏服装。已收录但没有部件资料的套装，暂时不能一键补齐。

登录后输入未收录的套装名，点“一键全部集齐”，系统会提示是否提报新套装；核对后确认即可，一次最多 20 个。提报后仍需审核。截图识别是可选入口，识别失败时可改用手动输入。

## 2. 陪审团：核对资料、投票与计票

陪审团做的是资料审核。大家对照游戏资料判断“确认正确”或“需要修改”，系统结合参与人数和等级票数决定通过、退回，或者继续等待。

### 2.1 先核对资料，不要只看名称就投票

1. 登录后点首页“陪审团”，用左右箭头切换事项；手机也可以左右滑动。
2. 核对服装名称、问题字段、待审核资料和可查看的游戏图鉴图片。
3. 资料还不完整时，按卡片列出的缺失或冲突字段补充，点“提交补充内容”。已确定的其他字段不要改。

补充者不能给自己提交的内容投票。自己提交过、补充过或参与过来源资料的事项，也不能自审。

### 2.2 核对完成后投票

1. 资料正确，点“确认正确”；需要修改，点“需要修改”。
2. 累计等级达到 Lv2 后，可在首次投票前填写 200 字以内的“复核意见”，说明判断依据。
3. 检查确认窗口后提交，看到“你已投”即完成。

同一份待审核内容只能投一次。投票和复核意见提交后不能修改；后来升级或降级，也不会改动已经投出的票。

### 2.3 人数和票数分别怎么算

每位用户都算 1 人，票数则按首次投票时的等级确定：

- Lv0、Lv1：1 票。
- Lv2、Lv3：2 票。
- Lv4：3 票。

例如，一位 Lv4 用户赞同，页面增加的是“1 人 / 3 票”，不是三个人赞同。页面同时显示人数和票数，就是为了避免把两者混在一起。

通过和退回要同时满足人数与票数条件：

- 通过：至少 5 位不同用户赞同，并且赞同总票数大于反对总票数。
- 退回重审：至少 3 位不同用户反对，并且反对总票数比赞同总票数至少多 3 票。
- 没达到以上条件：继续等待投票。

通过后，系统按本轮审核资料更新正式图鉴；退回只要求重新补充，不修改正式资料，也不会自动永久驳回。永久驳回是另一项管理员操作，见第 5 章。

## 3. 图鉴报错：报告已有服装的资料错误

“完善资料”用于补录缺失服装，“图鉴报错”用于纠正已经收录的服装。发现名称、分类、星级、属性或所属套装有误，请走报错入口。

### 3.1 提交一条可以核对的报错

1. 登录后点首页“图鉴报错”，按名称、短编号或分类找到目标服装。
2. 选择错误项目，把默认带入的内容改成你确认的正确内容；没有合适选项时，可按页面提示手动输入。
3. 点“选择图鉴图片”，上传能看清服装和正确资料的游戏内截图，检查预览。
4. 点“提交并转交陪审团”。

不要上传账号、联系方式或聊天内容。图片用于核对资料，只向报错者本人和有资格参与该事项的陪审员开放，不会公开给所有人。

### 3.2 提交之后，会发生什么

新报错会直接进入陪审团，不需要等待管理员转交。由其他合资格用户补充完整资料并投票，通过后才更新正式图鉴；刚提交时不会立即改资料。

到页面下方“我的报错记录”查看进度，必要时点“刷新”。报错者不能再补充、投票或终审自己的这项报错。

同一服装的新问题可能合并到已有审核事项。若审核内容改变，需要重新核对和投票，原记录会保留。网络提示结果仍待确认时，先核对记录，不要另建一份重复报错。

如果是希望增加或改善功能，而不是服装资料有误，请使用“优化建议”。

## 4. 积分制度：怎样得分、升级与查看排名

积分用来记录有效贡献，不是提交次数越多就一定得分。服装资料成功入库、补全或修正，报错建议被采用，才会结算对应贡献积分。

### 4.1 哪些行为会获得积分

| 有效行为 | 基础积分 |
| --- | ---: |
| 服装资料自动入库或管理员审核入库 | +10 |
| 正式图鉴空字段补全成功 | +5 |
| 重审修正通过 | +8 |
| 报错建议最终被采纳 | +5 |
| 对每份待审核内容首次有效投票 | +1 |

重复点击或重复请求不会重复加分。首次有效投票的 +1 不因该资料后来退回或驳回而追回。

### 4.2 原有等级与奖励不变

| 等级 | 页面名称 | 累计积分门槛 | 成功贡献的额外积分 | 每次陪审投票票数 |
| --- | --- | ---: | ---: | ---: |
| Lv0 | 初级搭配师，未解锁等级徽章 | 0 | 0 | 1 |
| Lv1 | 见习搭配师 | 500 | +1 | 1 |
| Lv2 | 资深收集者 | 2000 | +2 | 2 |
| Lv3 | 图鉴守护者 | 5000 | +3 | 2 |
| Lv4 | 奇迹编年史官 | 10000 | +5 | 3 |

等级额外积分只叠加在表中前四类成功贡献上，不加在投票的 +1 上。按奖励发生前的等级计算，升级当次和历史奖励不追补。铜、银、金、皇冠的等级主题不变，不新增管理员等级。

若报错最终推翻已采纳的原资料，系统按规则扣回与该错误资料相关的原贡献积分及其等级奖励，其他无关贡献不受影响，原记录仍保留。

### 4.3 在哪里看积分和权益

点顶部“个人中心”，查看总积分、当前等级、升级进度和已解锁权益。Lv1 增加本人积分流水；Lv2 增加本人贡献、投票记录及当月匿名社区统计；Lv3 增加最近 12 个月匿名统计；Lv4 增加匿名治理统计。不会因此看到别人的私密账号信息。

点首页“积分排行”，查看“总榜 / 当月榜 / 上月榜”。月份按北京时间统计，上月榜确定后，不随月中新积分重新排序。

如果个人中心显示月榜首 Lv4 体验，它只提供有效期内的 +5 贡献奖励、3 票票权和 Lv4 匿名治理统计，不改变累计等级，也不自动获得管理员或候选资格。

## 5. 管理员功能：审核、重新审核与任期管理

社区共治让更多人参与审核，但不改变原等级设计，也不削减站长权限。普通管理员依有效任期工作；站长就是超级管理员，完整保留业务治理、最终裁决、纠错、管理员治理和技术管理权限，可以选择不行使，但不会因此失去权限。

### 5.1 从哪里进入，谁可以处理什么

有效任期内登录后，首页显示“图鉴管理”。普通管理员可先在“个人中心”核对当前任期；到期后自动收回管理员权限。

| 事项 | 普通管理员 | 站长 |
| --- | --- | --- |
| 符合条件的新增服装多数审核 | 1 人可处理 | 保留审核与最终裁决权限 |
| 套装通过或驳回 | 2 位不同管理员确认 | 可单独执行 |
| 永久驳回 | 2 位不同管理员确认 | 可单独执行 |
| 有新证据，重新打开永久驳回事项 | 2 位未参加原处理的管理员确认 | 可单独执行，也可纠正自己此前决定 |
| 候选限制或撤销限制 | 3 位不同管理员确认 | 可单独执行 |
| 创建手动任期、提前结束别人的任期 | 不允许 | 仅站长可操作 |
| 优化建议的状态和可见性处理 | 不允许 | 仅站长可操作 |

共同确认必须由不同的、任期仍有效的管理员完成。同一个人重复点击不算多人。普通管理员不能终审自己提交、参与来源资料或已经投票的事项，也不能获得数据库后台或部署权限。

### 5.2 审核新增服装

普通管理员入口：“图鉴管理 → 新增服装审核”。

1. 核对服装的完整多数资料和支持人数。
2. 正确则点“按多数通过”，确认后采用多数资料；需要退回则点“填写原因并驳回”。
3. 查看成功提示和队列变化。少数不同意见仍保留，驳回允许提交人修正后重新提交。

这个队列只列出正式图鉴不存在、没有套装语义、完整多数资料至少有 5 位不同有效用户支持、没有最高支持数并列，且审核者未参与提交的新增散件。已有资料补全、报错、重审和争议项继续走陪审团，不能从这里直接改正式资料。

站长从“图鉴管理 → 散件仲裁”核对资料一致情况和不同意见，再使用页面允许的审核操作；最终裁决权限保持不变。

### 5.3 套装审核：两人确认同一个决定

普通管理员入口：“图鉴管理 → 套装审核”。

- 通过：第一位核对后点“确认通过”，记录为“1 / 2”；第二位用自己的账号核对同一套装，再点“确认通过”。完成后显示已通过，可到套装图鉴刷新核对。
- 驳回：第一位点“确认驳回”并填写原因；第二位查看“现有驳回提案”，认可后点“确认驳回”，不用重复填写原因。

“同一原因”就是确认第一位已记录的原因，不是两人各写一段再比较文字。一人通过、一人驳回，不会凑成两人通过。

站长进入自己的“套装审核”，点“批准入库”，或点“驳回”并填写原因，一人即可执行。

### 5.4 永久驳回：普通投票与管理员决定分开

入口：首页“陪审团 → 目标事项 → 管理员终审”。

1. 第一位合资格普通管理员填写理由，点“提交永久驳回”，检查弹窗并确认。
2. “1 / 2”表示原因已记录，还没有执行永久驳回。
3. 第二位合资格管理员查看已记录的原因，点“确认永久驳回”，再确认弹窗。
4. 完成后事项停止投票，显示已永久驳回，处理记录保留。

已投过这一项、提交过资料或参与过来源的人不能再做普通管理员终审。看到此类提示，请换合资格管理员，不是重新填写原因，也不是反复点击。

站长可在“站长终审”中填写理由并单独执行。站长按普通陪审员身份投票时，仍遵守不能自审和不能改票的投票规则。

### 5.5 出现新证据，重新审核

普通管理员入口：“图鉴管理 → 重新审核”。站长入口：“图鉴管理 → 决定纠错”。

1. 找到已永久驳回的事项，查看原原因，点“填写新证据并重新打开”。
2. 第一位未参加原处理的普通管理员填写新证据并提交；在“候选管理 → 确认记录”可核对说明和进度。
3. 第二位未参加原处理的普通管理员核对后，在同一事项填写与首次记录相同的新证据说明，再提交。
4. 显示已重新打开后，到“陪审团”刷新，重新补充资料和投票。

当前这个入口仍要求两人填写相同新证据说明，与永久驳回的“第二位直接确认”不同。原提交者、补充者、原轮次投票者和原决定确认者需要回避，后续按页面资格提示参与。

站长填写新证据后可单独重新打开，不受普通管理员的两人门槛或原处理参与者回避限制，也可纠正自己此前的决定。重新打开不等于资料已通过，原驳回和处理记录不会删除。

### 5.6 候选限制：三人确认，不能给自己操作

普通管理员入口：“图鉴管理 → 候选管理 → 候选限制”。

1. 第一位选择用户，填写开始时间、结束时间和原因，点“提交候选限制”。
2. 另外两位有效管理员核对同一对象、起止时间和原因，使用自己的账号填写相同内容并提交。
3. 到“确认记录”核对是否达到三人并显示“已执行”；待生效限制要到开始时间才生效。

撤销时，对同一条生效中或待生效的限制点“撤销排除”，由三位不同管理员填写相同撤销原因并确认。普通管理员不能排除自己，也不能管理站长身份。

候选限制不是封号，也不修改等级。站长可在“任期治理 → 候选限制”中单独新增或撤销。已过期、已撤销的记录保留在历史中。

### 5.7 怎样成为月度管理员，谁能设置手动任期

月度候选要求：月初确定名单时累计等级至少 Lv2，上月至少有 5 次获得正积分的有效行为，并且没有需跳过的身份或有效候选限制。等级额外奖励不另算一次行为，达到 Lv2 不等于自动成为管理员。

每月 1 日北京时间 00:05 确定上月榜，00:10 在冻结成功后轮换，最多 5 席；不足就留空，不降低门槛。排序仍为上月冻结积分降序、有效行为次数降序、最后有效行为时间升序，再按固定账号顺序处理并列。月中新积分不重排，退出、撤销或新限制后的空席按原顺序补位，同月已退出或被撤销者不再入席。

站长、已有有效手动或过渡任期的用户、已注销账号和命中有效候选限制的用户会被跳过。冻结失败时，不授予新月度任期；旧任期按时间自然失效。任期内等级降低不自动提前撤权。

手动任期只由站长管理：进入“图鉴管理 → 任期治理 → 任期”，选择用户，填写未来结束时间和原因，再点“创建手动任期”。最长 31 天，不占月度五席；提前结束时，找到目标任期，点“提前结束”并填写原因。

普通管理员没有手动任期权限。自己不想继续任职，可在“个人中心”点“退出任期”；主动退出不等于有权结束别人的任期。

### 5.8 查记录与处理其他事项

普通管理员在“候选管理”查看“候选名单 / 审核记录 / 确认记录”，站长在“任期治理”查看。看到“1 / 2”“1 / 3”是已记录但还未执行，不能把它当作最终成功。

站长还保留“权限大盘”“优化建议”和历史“图鉴报错”的管理入口。新报错已经直接进入陪审团，不用重复转交；优化建议的评估、重新评估和可见性处理仍只归站长。

任期有效却没有管理入口，或结果仍待确认时，先查看记录、刷新或重新登录；仍有问题，反馈“角色、页面、操作、实际现象、北京时间和截图”，不要发送密码或验证码。

## 6. 项目寄语：如果它帮到了你，欢迎支持

做这个项目，最开始是希望搭配时少一点反复查找，让自己的衣柜真正派上用场。慢慢做下去才发现，一个看起来简单的“算一下”，背后还有图鉴整理、资料核对、计算规则、账号和衣柜同步，以及一轮轮修改和测试。

把功能做出来是一部分，让它在不同设备上稳定运行、让错误资料能够被纠正、让大家的贡献得到记录，又是另一部分。网站也需要持续承担服务器、域名、存储和日常维护。这个项目还有不少可以改进的地方，会继续认真处理大家实际遇到的问题。

如果搭配器帮你省了时间，或者你认可这份投入，也愿意支持它继续维护，欢迎在能力范围内请我喝杯饮料。没有金额要求，不用勉强；每一份支持都很感谢。

想打赏时，点网站页脚“打赏”，按页面展示的微信或支付宝二维码操作。手机上可以长按保存，再到对应应用识别。

项目会继续免费使用，打赏完全自愿。不打赏也欢迎常来：补一件准确的图鉴资料、认真投一票、指出一个问题，都是对这个项目很实在的帮助。希望它能成为大家搭配时顺手、可靠的小工具。
