# 数据库变更记录

## 0. 使用说明

本文档用于记录 Supabase 数据库的每一次结构变更、RPC 变更、RLS 变更和批量数据变更。

记录原则：

1. 每个 migration 或线上 SQL 操作都必须有记录。
2. 生产执行前先填写“变更计划”。
3. 生产执行后补充“执行结果”。
4. 批量数据更新必须记录预检 SQL、影响行数和复查结果。
5. RPC 替换必须记录旧函数备份方式和回滚方案。
