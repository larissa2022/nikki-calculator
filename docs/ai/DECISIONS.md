# 决策记录

用途：记录已经确认的产品、技术和流程决策，避免重复讨论或后续实现口径不一致。

## 1. AI 协作流程

- ChatGPT 负责整理任务、写任务单、判断下一步。
- Codex 负责按任务单执行。
- 用户只做功能审核、流程把控和产品测试。
- Codex 完成后写 `CODEX_REPORT.md`。

## 2. 数据库安全

- 不直接操作 production。
- production 写库脚本不放入可提交路径。
- 涉及数据库前必须确认 dev/prod 状态。
- 数据库任务必须先看数据库安全文档和变更记录。

## 3. 管理员审核卡片文案

- 不使用：版本、变体、字段组合、冲突版本、一致提交。
- 使用：资料一致情况、最多人认可、不同意见、可按多数入库、需要继续收集。
- 5 人以上相同且无不同意见：可入库。
- 5 人以上相同但有不同意见：可按多数入库。
- 有不同意见但未达到 5 人：需要继续收集。
- 人数不足保持“人数不足”。

## 4. 当前推进原则

- 下一步优先做 Preview / production 人工回归。
- 暂不直接开发积分、陪审团、重审、排行榜等大模块。
- 需求文档后续需要根据已实现功能做一次收口更新。
