# 当前任务看板

> 最后更新：2026-07-20 21:42（北京时间）

## 当前任务

- 让登录用户在个人中心看到由积分流水计算的可信累计积分，并用同一积分结果计算社区头衔。

## 为什么做

- 个人中心仍读取可能与积分流水不一致的历史档案字段，会造成积分和头衔展示失真。

## 已经完成

- 已确认积分流水是积分唯一事实源，现有只读结果仅允许登录用户读取自己的累计积分。
- 个人中心的累计积分和社区头衔已改用同一权威汇总；查询异常会提示重试，不再回退到历史档案字段。
- 自动测试 7 项与生产构建通过；development / Preview 登录态验收确认无积分流水时显示 0 分、初级搭配师、1 票权重及积分流水来源。

## 当前进度

- 完成阶段：开发、自动验证和登录态业务验收均已完成，可以进入下一任务。

## 下一步

## 需要负责人决定

- 不需要决定；本轮未改变积分规则、等级门槛或权限边界。

## 通用边界

- 不修改数据库、Supabase 对象、权限、migration、env、Vercel、`main` 或 production。
- 不开发排行榜、月榜、贡献者展示或积分写入链路。

## Rollback

- 如需撤销，revert 本轮业务提交，恢复个人中心原展示；不回退 DB-2 或改写数据库历史。
- 查询失败时保持个人中心可用并提示重新读取，不回退到非权威积分字段。
