# Planning Prompt

用途：ChatGPT 规划任务时使用，先整理范围、风险和执行顺序，不直接替用户做高风险决策。

```text
请基于当前项目文档和最新用户目标，输出一份执行计划。

要求：
1. 明确任务目标。
2. 明确允许修改和禁止修改的范围。
3. 列出当前已知依据。
4. 识别需求风险、数据库风险、生产环境风险。
5. 遇到需要用户决策的地方，列为“待确认”，不要直接推进。
6. 输出建议下一步，按低风险 / 中风险 / 高价值分类。
7. 如发现可沉淀经验，只提出 Lesson / Pattern / Rule Candidate，不批准正式 Rule。
```
